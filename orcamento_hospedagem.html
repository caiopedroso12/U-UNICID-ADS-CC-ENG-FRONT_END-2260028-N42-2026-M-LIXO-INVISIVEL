Recomendação e sustentabilidade

O site é estático: só HTML, CSS, um JavaScript pequeno e imagens SVG. Não há banco de dados nem servidor próprio, então o custo pode ser zero. Como o projeto já está no Railway, a sugestão é manter lá durante a avaliação e deixar o GitHub Pages como alternativa gratuita. Domínio próprio é opcional.

Sobre hospedagem de menor impacto: não encontramos fonte confiável que compare a pegada de carbono entre estes provedores, então não vamos afirmar qual é mais verde. O que está ao nosso alcance é manter o site leve (poucas requisições, imagens vetoriais, sem bibliotecas pesadas), e perguntar ao provedor sobre uso de energia renovável. Para o contexto energético, veja o relatório da IEA sobre data centers (abre em nova aba).
